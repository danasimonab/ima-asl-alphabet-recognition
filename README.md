# ima-asl-alphabet-recognition
Classify images of hand gestures for the American Sign Language (ASL) alphabet.

• Problem Description: Classify images of hand gestures for the American Sign 
Language (ASL)
alphabet.
• Model Suggestion: A lightweight CNN designed for mobile/edge execution (e.g., MobileNetV3).
• Dataset: ASL Alphabet dataset [12].
• Starting Point: "Sign Language Recognition" [46].
• Extensions:
– Optimize and export the model to TensorFlow Lite or ONNX Runtime.
– Build a real-time inference script using OpenCV to capture webcam frames.
– Apply model quantization (INT8 or FP16) and measure the impact on accuracy and speed.
